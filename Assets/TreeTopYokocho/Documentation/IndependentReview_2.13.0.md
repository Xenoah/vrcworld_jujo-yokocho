# v2.13 独立照合・制作プレビューの記録

## 実際の制作データ

凍結済みv2.12ソースZIP（165,577,598バイト・509項目・CRC正常）を読み取り、現行v2.13と独立した2,300項目で照合しました。失敗は0です。

- 8個の雲の完全ペイロードだけが承認済みの値へ変化。他の1,047描画バッチは全バイト一致
- 雲のX/Y、UV、Color32、面順・数は一致。Zのみfloat64制作処理後の正確なfloat32値へ変更
- 全8分割ファイルの長さ・SHA-256・結合結果・gzip展開結果を照合
- 全体3,188,682頂点・2,631,065三角形・1,055バッチ・108,150,271ネイティブバイトは同じ
- gzipは32,934,463バイト。前版比+1,242バイト。Windowsワールド容量とは異なる
- 衝突形状・圧縮衝突データ、44画像とimport設定、7シェーダー、C#ソース、元の雲ジェネレーター、夕景設定は全バイト一致
- 98材質のうちCloudSeaSilverの説明用cloudBaseZだけ110→93.2へ訂正。描画に使用する設定は維持
- マニフェストの変化は版番号・真偽値フラグ・28中心Z・2高度境界・説明情報・上記材質値の34項目だけ

## 高度と通路

雲の実高度93.8160095–123.6039963mを再計算。最大0.15mの揺れ込みでもL1の床134mから10.2460037m下です。中央の開口と経路は水平方向を一切変更していません。元の全オフライン検査と14項目の雲ソース検査、現行出力と不正変更の9,154判定を実行し、すべて通過しました。最終の実行結果は[検証記録](Validation.md)と各JSONを参照してください。

## 画像と実行上の限界

全景は建築確認用の高いカメラ、展望橋は既存の床支持が確認できる立ち位置からの視点です。最終画像では同じ実形状と共有した夕景設定を使い、形状・制作元・描画条件のハッシュを照合しました。全景と展望橋で雲の肩が厚くなったことを確認。独立した最終画像確認でも、両画像・11個の制作元照合・保持したRaw画像が一致し、新しい浮いた稜線片や突起は見つかりませんでした。雲の半透明表現と遠景の山稜・樹冠の簡略化は残っており、写実的な完成品とは扱いません。

Blenderの材質近似はUnityシェーダーと画素単位に同一ではありません。メッシュ数が同じでも透明面の重なりや法線・見え方は変わるため、GPU速度が維持されるとは主張しません。

Unity/C#/Udon/Shaderコンパイル、ベイク、Windows Build & Test、VR実機、FPS、約50MBの最終ビルド容量は未確認です。指定経路と仮定した身体寸法のオフライン検査は、Unity物理や任意のアバターの代わりにはなりません。
