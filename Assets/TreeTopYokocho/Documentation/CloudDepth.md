# 雲海の厚み — v2.13

上端の124mを基準に、既存の雲のZ座標だけを下方向へ2.2倍に広げました。横から見える雲の肩と谷に量感を増すための限定した改修です。半透明のメッシュ表現であり、体積散乱を計算する雲ではありません。

## 保持するもの

- 28バンク、252個の丸み、36,288三角形、20,412頂点、8空間バッチ
- 雲のX/Y、UV、頂点色、面順、材質の描画設定、既存シェーダー
- 他の1,047描画バッチ、乱数列、階段・床・透明壁、49席、12階層移動先
- 新しい画像、材質定義、ライト、シェーダーパス、衝突形状は0

`cloud_depth` が文字列や数値ではなく真偽値の `true` の時だけ有効です。旧ジェネレーターは変更せず、float64の制作頂点に適用してから既存のfloat32書き出しを行います。既に変形済み・書き出し後の入力や不正な形状は、部分変更を残さず拒否します。

## 高さと開口

実際の書き出し頂点は93.8160095–123.6039963m。シェーダーの最大0.15mの揺れを加えても123.7539963mで、最下段の横丁L1=134mより10.246m下です。記録上の保守的な包絡は93.2–124mです。

元の実三角形から求めた中央の水平開口半径は51.247m。雲と同じ高度帯を横切る実階段コライダーの全バッチを含めても、雲の水平投影から9.847m離れています。北の街道・城郭と南の海へ向かう指定線分も実三角形と交差しません。任意の場所から必ず同じ眺めが得られるという保証ではありません。

## 検査

- 既存の603バッチ保護基準は作り直さず、雲8件だけを独立した承認済みペイロードへ置換
- 雪8件・樹冠分割8件・舞台19件の個別契約は維持
- 旧雲と新雲の完全なデータ、乱数不変、反復拒否、float64処理順、包絡と揺れの上限を可搬テストで確認
- 現行全体の形状・指定動線・床支持・頭上・透明壁のオフライン検査は[検証記録](Validation.md)を参照

[ソース単体検査](cloud_depth_source_validation.json)、[厳密なペイロード契約](peer_contract_validation.json)、[高度検査](altitude_validation.json)。

## 描画上の制限

形状数が同じでも横から見える透明面積や重なりは変わります。VRChatでの透明物ソート、片目ごとの見え方、GPU負荷と最終Windows容量は未測定です。Blenderプレビューは実形状と近似材質による確認であり、Unityシェーダーの実行結果ではありません。
