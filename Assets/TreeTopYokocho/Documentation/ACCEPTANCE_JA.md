# Windows / VRChat 受入チェック

以下は未実施の実機チェックです。オフラインの幾何学試験に合格していても、VRChat の CharacterController やアバターの姿勢を再現した保証にはなりません。

## 起動・基本操作
- SDK / UdonSharp / 5シェーダーに赤いコンパイルエラーがない
- Build World、Physics Audit、Budget Audit が完了する
- Windows Build & Test でワールドに入り、4スポーン位置で地面に立てる
- 8店舗の49席すべてで座り、降りると床上に戻る
- G0 / L1 / L2 / L3 の12行先ボタンが正しい階へ移動する

## 落下防止
- L1到着デッキ、L2環状路、L2茶屋デッキ、L3枝路地、L4展望台を外周・内周の両方から歩いて確認する
- R01 / R02 / R03 の両側、上下の入口、踊り場、手すり接合部で斜めに押し歩き・ダッシュ・ジャンプする
- 屋根と手すりから外へ飛び出そうとして透明壁を通過しない
- 小柄・長身のアバター、デスクトップ、VRで確認する。VRの物理移動・頭の突き抜けは通常の移動衝突と異なるため別に確認する
- 席から降りた直後と階移動直後に安全復帰処理が誤作動しない
- 想定外に落下した場合の床上復帰を、テスト用複製シーンで確認する

## 見た目・負荷
- ライトベイク完了後、提灯の間接光と店内の暗部、瓦・古材・樹皮の法線を確認する
- 両眼で空・水面・湯気・葉が一致し、片目欠けやちらつきがない
- 湖岸の灯り、寺院、森、複数の山稜が途切れず見える
- 最も重い環状路と俯瞰位置でCPU/GPU時間、描画数、VRAMを測定する
- 1人だけでなく想定人数とアバター負荷でも確認する

## 容量
- SDKが出力した実際の Windows .vrcw / AssetBundle ファイルのバイト数を記録する
- 目標はおおむね50MB。ソースZIP、GLB、Unitypackageのサイズと区別する
- 超過時はまずライトマップ総量、反射Probe、未参照アセット、遠景テクスチャ、メッシュ圧縮を確認する
- このチェック完了と公開の承認を得るまでは、公開済み・実機確認済みと扱わない
