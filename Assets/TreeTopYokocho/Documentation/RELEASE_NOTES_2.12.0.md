# v2.12.0 — 舞台の瓦と雪山の表情 / Source pre-release

中央の舞台へ、丸い断面の瓦、薄く開いた軒先、重なりのある棟、梁の木栓と垂木を追加しました。床と梁は既存の粗い木材PBRセットへ切り替え、鏡状の光沢を抑えました。北の山脈は、露岩につながる積雪の濃淡を付け、均一な白い帽子の印象を抑えています。

実際のモデルのBlender Cyclesプレビューです。屋根の全景は建築確認用の高いカメラです。Unity／VRChatの実機画像ではありません。各画像のJSONに実データと描画設定のSHA-256を記録します。

## 変更量

- 舞台: 25,012三角形、4バッチ追加。既存の3材質を共有し、新規画像は0
- 雪山: 8バッチのRGBだけ変更。位置・UV・面順・alphaはそのまま
- 全体: 2,631,065三角形、1,055描画バッチ
- ネイティブ制作形状: 108,150,271バイト、gzip 32,933,221バイト。前版比はそれぞれ+1,257,759 / +278,604バイト
- 当たり判定、席、階層移動先、指定動線は維持

制作データ容量はWindowsワールド容量ではありません。約50MBの最終ビルド目標は未測定です。
