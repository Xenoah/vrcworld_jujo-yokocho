## Nonblocking follow-ups and limits

S05's original pale-framed rectangular washi pendants read rather modern under neutral light. A darker timber/lattice refinement is a separate future geometry revision, not part of this preserved-geometry checkpoint. Initial S04/S06/S07 front-camera frames cropped a sign-board border while retaining all glyphs. The final comparison gallery uses camera-only corrections with the same standing eyes, restoring complete borders without moving the shops.

C# syntax checks and source property checks do not prove Unity compilation. Actual shader generation, bake/meta behavior, reflection probes, face color under different avatar materials, stereo consistency, runtime navigation, performance and Windows build size remain unverified.
