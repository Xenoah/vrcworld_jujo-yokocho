# v2.8.0 — 板床の造作と店員入口 / Source pre-release

Windows向けVRChatワールドの制作ソースです。約50MBは最終ビルドの目標で、Unity・Windows・VRChatによる実行／容量確認はまだ行っていません。

## 今回の改修

- 継目が二重に見えていた床を、実際の板割り・小さな面取り・浅い釘穴・補修板を持つ板張りに更新。既存の木材スキャンを使い、新しい画像は追加していません
- 8店舗の左側に店員入口。カウンターを30cm短くし、暖簾を紐で巻き上げ、提灯を高く移動。49席と客席退出位置は維持
- 物理壁以外の描画物も調べる検査を拡張。枝3制御点、昇降機のボタン取付位置、4本の干渉する電柱、W02と環状路の検査動線を修正
- 葉の繰り返しUVをUnityでもRepeatへ統一。風変形をUV依存から位置依存へ変更し、裂け・過大変形・描画境界外への移動をソース式と実頂点で検査

## 規模と検査

- 描画ソース: 2,630,961三角形、1,047バッチ
- 板床部分は178,564→99,752三角形（44.1%減）。板ごとのUVを増やしたため、全体の編集用gzipは31,863,390→32,452,512バイトへ増加しています。三角形削減とダウンロード容量削減は同じではありません
- 床・階段・透明壁の衝突メッシュはv2.7と完全一致。カウンターの16個のBoxColliderのみ、指定した幅と中心を変更
- 49席と12階層移動先を維持。12個の操作ボタンは西側へ移設し、内側を向けました
- 樹木・遠景・樹冠の保護対象599バッチのうち、SupportingBranchesの1バッチのみレビューした形状へ変更し、他598個を維持

最終結果は[検証記録](Validation.md)と[独立レビュー](IndependentReview_2.8.0.md)を参照してください。入口の確認は指定した短い通路、経路検査は記載の身体寸法と領域に限ります。
