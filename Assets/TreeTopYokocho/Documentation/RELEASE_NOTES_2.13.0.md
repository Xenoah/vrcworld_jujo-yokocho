# v2.13.0 — 雲海の厚み / Source pre-release

横丁の下の雲を、上端と水平方向の切れ間を保ちながら下方向へ厚くしました。横から見える肩と谷の量感を増し、中央の階段と北・南への実際の眺望開口を維持しています。

## 画像

[雲海と横丁の全景](../../../Preview/Blender_cloud_depth_world.png)
[展望橋からの雲海](../../../Preview/Blender_cloud_depth_lookout.png)

実モデルのBlender Cyclesプレビューです。全景は高い建築確認用カメラです。Unity／VRChat実機画面ではありません。画像のJSONには形状・制作元・描画設定のSHA-256を記録しています。

## 変更量と検査

- 雲8バッチのZ座標だけを変更。他の1,047描画バッチは維持
- 全体の2,631,065三角形・1,055バッチは同じ。新しい画像・ライト・シェーダーは0
- 実雲形状93.816–123.604m。最大揺れ込みでもL1の床より10.246m下
- ネイティブ制作形状108,150,271バイト、gzip32,934,463バイト（前版比+1,242）
- 当たり判定・49席・12階層移動先・指定動線は維持
