# v2.10.0 — 店先の鉢と小さな緑 / Source pre-release

Windows向けVRChatワールドの編集用制作ソースです。約50MBは最終ビルドの目標で、実ビルド容量は未測定です。

## 今回の改修

8店舗の同じ小さな鉢を、縁と内壁のある素焼き鉢、窪んだ土、葉柄までつながる植物へ変更。しそ・チャイブ・三つ葉・山椒を意識した4系統の姿を配置しました。既存の画像を再利用し、配置中心・元の水平範囲・歩行動線を維持しています。

[造形・配置・容量の内訳](HerbPlanters.md)

## 規模と検査

2,606,053三角形、1,051描画ソースバッチ。新規材質5、追加テクスチャ0。世界の乱数列と保護対象603バッチ、床・階段・透明壁、49席、階層移動と指定通路を維持しています。

[検証記録](Validation.md)と[独立レビュー](IndependentReview_2.10.0.md)。オフライン検査は指定領域と仮定した身体寸法に限ります。

## 文書の訂正

前版の詳細文書にあった「実写Kawara」は誤記でした。瓦の既存tile_clay画像一式は手続き生成PBR素材で、実写スキャンは木材・樹皮・岩の4セットです。該当する説明を訂正しました。
