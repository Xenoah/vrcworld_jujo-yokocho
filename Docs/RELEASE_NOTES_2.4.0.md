# v2.4.0-source-preview — 地上から樹冠まで歩ける階段

地上G0から高さ112mの樹冠展望路へ、連続して上り下りできる通路を追加。

- 749段、蹴上146〜150mm、踏面261〜523mm。物理床は連続した斜路
- 階段幅2.8m、透明壁の内側間隔2.56m。露出端は高さ8mの非描画Colliderで保護
- 地上、到着デッキL1、展望デッキL4と接続。既存の壁と手すりを接合部だけ開口
- 樹冠の馬蹄形展望回廊と見える支え梁。上り口は天井・壁に塞がれない切り欠き
- 109灯の照明、105区間の連続した電線
- 雪境界の不自然な孤立した岩模様を穏やかな境界へ修正

## 検証

実際の全衝突メッシュと店舗BoxColliderを読む独立検査に合格。

- 2,053通路点、10,261床支持プローブ、4,940連続移動区間
- 半径0.25m、身体高さ1.65m、頭上2.2mの余裕を対象に確認
- 全5,220壁レイ、地上・L1・L4の3接合部
- 既存通路の目的地接続、49席退出先、12移動先も再確認

[階段検査の生結果](crown_validation.json)、[仕様と再検査方法](CrownStairs.md)、[検査全体](Validation.md)
