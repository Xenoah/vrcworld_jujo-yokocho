# 最終制作ソース v2.19.0 の確認メモ

## 今回の内容
- 8店を別々の建築・内装・椅子・看板に作り直しました。スナック、カクテルバー、音楽バーは3店、全体の37.5%です。
- RPG風の店名、日本語の書体、店舗ごとの照明色を設定しました。暖色だけでなく、ミント白、月白と翡翠、青緑、藍色、淡い薔薇色を使っています。
- 8店に実際の厚みを持つ突出看板、3店に輪郭の異なる旗を追加しました。茶房は木枠、木彫りの月と茶器、留め具付きです。
- 平面の海や未使用頂点、遠景の内部面を限定して削減しました。近くの手仕事や葉を一律に簡略化していません。

## 数量と制約
現行は2,708,881頂点、2,304,649三角形、1,145ソースバッチです。開始時のv2.14に比べて491,389頂点、344,958三角形を減らす一方、ソースバッチは87増えています。ソースバッチ数は実測描画コール数ではなく、FPS改善を保証しません。

49席のIDを保持しています。指定した身体寸法の208必須アクセス検査を実形状に対して実行していますが、任意のアバター体格、実際の座り方・立ち上がり、VR機器の動作を保証するものではありません。

## 見え方の注意
茶房の突出看板は、近くでは木彫りの月と茶器を確認できますが、屋根影に入る接近方向では紋章を判読しづらい状態です。主看板の店名は別に読めます。この点を隠すためのライト追加や画像だけの増光は行っていません。

画像はすべて実モデルのBlender近似です。Unity側のベイク、反射、シェーダーのコンパイル、両眼表示、VRChat実行、FPS、実配信サイズは未検証です。特にBlenderの点光源による鏡面反射は、UnityのBakedライトと同等ではありません。
