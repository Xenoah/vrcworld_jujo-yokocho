# 板張りと店内への入口 — v2.8.0

## 歩く床の造作

床の実形状に沿って、280mm幅の板を長さ1.8 / 2.4 / 3.0mで組み合わせます。継目は600mmの下地グリッド上でずらし、2.8mmの面取りと深さ3.8mm以内の溝で光を拾います。釘は浮いた飾りではなく、浅い穴の中に置いた小さな鍛造頭です。

既存のCC0木材スキャンから、撮影済みの釘や板境界が入らない部分を板ごとに選びます。写真の継目と実形状の継目が二重に重なる問題を避け、少数の補修板と控えめな色差を加えました。新しい画像資産は追加しません。

物理床の輪郭・上面・衝突データは変更しません。浅い溝の下には連続した描画用の板床があり、開いた穴や空へ抜ける隙間にならないよう、凹形状・穴・細い先端を含めて検査します。書き出したfloat32の形状にも別の面積・境界検査を行います。

## 店員側の入口

8店舗の片側のカウンター端を少し短くし、対応する物理BoxColliderも同じ形に更新します。丸椅子・着席位置・客席の退出位置・柱・落下防止壁は維持します。入口の暖簾は巻き上げて紐で留め、提灯を小さく高く配置します。

検査対象は入口とその先の短いカウンター内側の通路です。店の奥全体が任意のアバターで歩けるという意味ではありません。狭いS03では固定された丸椅子を避ける曲がった進入経路を使います。

## 葉のプレビューとUnity設定を一致させる修正

葉の画像は繰り返すUVを持つため、Unity側もRepeatへ揃えます。旧Clamp設定を実際のUVへ適用すると、透明な画像の端が広がり、葉の一部が欠けることを投影比較で確認しました。既存のBlender画像で見えていた配置・大きさを維持する修正です。

風の頂点移動は、法線用に補修されたUVから切り離します。同じ位置の頂点は同じ滑らかな波で動き、分割された葉の先端が裂けない式に変更。振幅パラメータは0〜0.08に制限し、その全範囲を含むよう描画境界を拡張します。

これはHLSLの式と実際の頂点を照合するソース検査です。UnityによるShaderコンパイル、GPU描画、ベイク、VRChat実機は別途必要です。実施結果と件数は、最終生成後のValidationとJSONを参照してください。

## 歩行動線と実際の飾りの干渉

物理壁だけの検査では見つからなかった、樹皮・昇降機の案内板・電柱との重なりを追加検査で発見しました。枝の3つの制御高さを下げ、支持する枝の根元や床を保持します。昇降機のボタンは西側の木製取付板に並べ、内側へ向けました。目的階の移動先は変えません。

W02は既存の柱を避ける折れ線、環状路はR01の到着側囲いを避ける短い内寄りの経路を検査線として定義します。既存の床形状・階段・透明壁は変えません。別の通路や客席の移動範囲と重なる候補電柱は置かず、残る支柱同士だけを電線でつなぎます。

この修正と合格範囲は、任意の場所を自由に歩いたときの完全な衝突保証ではありません。全体の操作感と多様な身体寸法はUnity/VRChat実機で確認する必要があります。
