# 独立レビュー — v2.10.0 source preview

## 実際の書き出しデータ

凍結したv2.9ソースZIPと現行出力を別の読み取り専用検査で比較しました。

- 現行バイナリを対象とする3,480の契約・不正変更検査と、131の独立した統合検査に合格
- 1,051バッチ、2,606,053三角形。既存の保護対象603バッチを厳密に維持
- 新しい鉢・植物32バッチは、8店の元の位置へ独立に生成したデータと位置・UV・頂点色・面順まで一致
- 無関係な共通1,011バッチはv2.9と同一。木部8バッチも新旧の植物の枝だけを索引付き部分メッシュとして取り除くと、残りの頂点共有・属性・面順まで同一
- 新しい植物は元の水平凸包と床高さの中に収まり、ワールドの乱数列を維持
- 49席、階層移動、固体BoxCollider、透明壁、床・階段と指定通路のメタデータはすべて不変
- テクスチャとそのメタデータ89ファイルは名前・バイト列とも不変。追加した5材質は既存画像を参照し、通常の不透明な表面として描画
- 圧縮分割8ファイルのハッシュ、結合、解凍後のバイナリを照合

衝突バイナリSHA-256は `51e395fbea8f6d29ffbebe76bb484f465c671508f93bf75afa9294ccff630ddb` のままです。

見た目の生メッシュは106,892,512バイト、gzipは32,654,617バイト。生データの実際の増加は493,608バイトです。これはソース形式の測定で、VRChatのダウンロード容量ではありません。

## 画像

今回の入力GLB SHA-256は `6659d24bd0d8838f87110c4c6f664b7e895320f9d416cbc6d71fa59357ad4a2a`。

店先のしそ風・三つ葉風の2視点について、実モデルのBlender/Cycles画像を確認しています。鉢の開いた縁、窪んだ土、葉柄からつながる葉が読み取れ、確認した画像に新たな目立つ貫通は見つかりませんでした。柱の陰になる土は暗く、VRでの照明や細部の見え方は別途確認が必要です。

最終1280×800・64サンプル画像2枚についても、別の目視レビューを完了しました。画像の入力GLB、未処理PNGのSHA-256、保存用コピーのPNG・JSONの完全一致を確認しています。

## 検査の範囲

指定領域と仮定した身体寸法によるソース・幾何学検査です。任意アバター、ルームスケール移動、UnityのCharacterControllerやネットワーク挙動を再現するものではありません。

既存の樹冠橋のGLBの2個のゼロ法線は前版と同じ状態です。[前版の制限](IndependentReview_2.9.0.md)を継続します。

Unity/C#/Udon/Shaderコンパイル、ライトベイク、Windows Build & Test、VR実機、FPS、実際の圧縮ワールド容量は未確認です。
