# 店先と手仕事のディテール — v2.7.0

## 今回の対象

歩いて近づいた時の質感と、8店舗それぞれの顔を作り直しました。見えない落下防止壁、床、階段、49席と12階層移動ボタンの位置は維持しています。

- 店ごとの紋、藍・生成り・弁柄・深緑の暖簾、読める日本語の木看板と短冊
- 面取りされた木部、長手へ沿う木目、木栓、方杖、金具、引手、雨樋
- 木製の丸椅子を、木目のある座面・開いた脚・貫を持つ形へ交換
- 和紙提灯の紋が胴全周へ引き伸ばされないよう、UVと紙・骨・吊り手を修正
- 炭火、麺、出汁、酒、茶、季節菓子の道具・器・料理・棚を別々に作成
- 曲がったデッキの手摺は、各ポリゴン端で柱を重複させず、連続した線へ配置

## 小さな資産を共有

店先は2048×2048のアトラス1枚、3材質。食器・食品・竹・布・瓶は1024×512の共有アルベド・法線・ARMを使います。木材の写真スキャンは既存のCC0資産を再利用しています。日本語フォントは制作時のみ参照し、フォント本体は配布しません。

過剰なポリゴン追加を避けるため、遠くから見えにくい棚の器、手摺の細い子柱・小さなボルト、提灯の骨は軽量な形状へ調整しています。GPU負荷・VRChatの圧縮ダウンロード容量はUnityでの実測が必要です。

## 再生成

`Source/build_world.py` が `shopfront_identity.py`、`counter_craft.py`、`timber_craft.py`、`railing_craft.py`、`lantern_craft.py` を呼び出します。店先・料理の乱数はワールドの乱数から分離し、元の樹木・遠景・樹冠経路が動かないことを599バッチのハッシュで確認します。

`python Source/counter_craft.py --audit` は器や小物の有限値・UV・縮退三角形・再現性を検査します。`Source/validate_shop_details.py` は実際の出力三角形と、席の退出先・着席胴体・指定通路の検査用領域を照合します。

## プレビューの意味

画像は実際に出力したGLBをBlender Cyclesで描画したものです。視点は実床の歩行領域上に置いています。任意の `--aov` で実シーンのアルベド・法線パスを保存し、標準のOpen Image Denoiseへ渡せます。生成AIによる描き足しや補正は行っていません。元のノイズ付きレンダーはローカルの `Preview/Raw/` に保持します。

Unityの独自Shader、ベイク済みライティング、VRChat実機の画面ではありません。画像のJSONに、入力GLBのSHA-256、カメラ、レンズ、サンプル数、ノイズ除去方式を記録します。

## 当時の制限（v2.7時点）

店員側への通路は、後続v2.8で修正・再検査しました。[現在の動線説明](DeckAndAccess.md)を参照してください。

- 食品は極端な接写ではまだ模型的な部分があります。自然な形と表面の仕上げを継続します
- 店のカウンター脇は従来から約0.45mの隙間しかなく、店員側へ入る経路としては今回の0.50m径・頭上2.2mの検査条件を満たしません。客席・退出先の合格と区別しています
- この静的な形状検査は、任意アバター、手を伸ばす動き、VRの物理移動、Unityの物理処理を再現しません
- Unity / Udon / Shaderコンパイル、Windowsビルド容量、VRでの見え方は未検証です
