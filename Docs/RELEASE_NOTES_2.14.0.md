# v2.14.0 — 暖簾の仕立て / Source pre-release

8店舗の暖簾を、薄い布の実体、裾の折返し、竿を越える布の輪、節のある丸い竹竿へ改修しました。吊り点から浅い折れを作り、文字や紋と藍色は維持しています。

## 画像

[通りから見上げた店先](../Preview/Blender_noren_eaves.png)
[暖簾のゆるい折れと裾](../Preview/Blender_noren_detail.png)

実モデルのBlender Cyclesプレビューです。Unity／VRChat実機画面ではありません。画像ごとのJSONに実形状・制作元・描画条件のSHA-256を記録します。

## 範囲

- +18,542三角形、+11,588頂点、正味+3バッチ
- 全体2,649,607三角形・1,058バッチ。ネイティブ制作形状108,651,058バイト、gzip33,062,783バイト（前版比+128,320）
- 新しい画像・材質定義・シェーダー・コライダーは0
- 巻き上げた店員入口、看板、品書き、灯り、107個の元の部品を維持
- 当たり判定・49席・12階層移動先・指定動線は維持
