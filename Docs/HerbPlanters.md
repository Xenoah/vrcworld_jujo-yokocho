# 店先の小さな鉢植え — v2.10.0

8店舗の同じ位置に置かれていた鉢を、縁・内壁・高台のある素焼きの鉢と、土から生える小さな植物へ作り直しました。

- S01/S05: しその葉を意識した鋸歯と広い葉
- S02/S07: 細い葉が上へ伸びるチャイブ
- S03/S06: 三つ葉を意識した葉のまとまり
- S04/S08: 木質の軸と小葉を持つ山椒風の姿

植物学的な標本ではなく、店先の雰囲気に合わせた環境小物です。鉢の色を2系統に分け、口縁の厚み、土の窪み、小さな土粒、葉の反りと葉柄の接続を造形しています。最大高は約0.494mです。

## 配置と安全性

中心位置は前版から変更していません。全頂点の水平範囲は、元の植物の外接矩形と凸包に収まることを確認しました。風で通路へはみ出さないよう、この短い鉢植えには大きな樹冠の風シェーダーを使わず、通常の不透明なSurfaceシェーダーを使用しています。葉は切り抜きカードではなく輪郭のある形状で、表裏を独立した頂点と面で作っています。

店舗の既存Food/Foliage0〜3の40バッチが、植物だけであることを実データから確認し、新しい32バッチへ置き換えました。新しいグループはありません。既存のDarkTimberバッチに含まれる旧茎だけを取り除き、山椒の木質軸を追加しています。

世界全体の乱数列を変えないため、旧処理と同じ10回のスカラー乱数を消費し、小物固有の造形には独立した乱数を使用します。保護対象603バッチの位置・UV・色・共有頂点・面順は変更しません。

## 再現と検査

`Source/test_herb_planters.py` は出典を記した小さな旧植物の参照関数と比較し、ラッパー／配置呼出し、乱数列、他の材質・形状の不変、各店の元の水平範囲、葉の表裏、UV、鉢の開口と土の高さなど10項目を検査します。

`Source/test_peer_culling_contract.py . --actual` はherb_plantersが真のときだけ指定した40削除・32追加を許可し、それ以外の追加・別名・重複・色違いの取り違えを拒否します。期待データは自動更新しません。全体の床・透明壁・指定動線の検査も再実行します。

プレビューのカメラは既存の客席退出位置に立った高さから鉢へ向けています。画像は今回のGLBをBlenderで描画したもので、Unity/VRChat実行画面ではありません。
