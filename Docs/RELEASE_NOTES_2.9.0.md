# v2.9.0 — 瓦・雨樋・料理の近景仕上げ / Source pre-release

Windows向けVRChatワールドの編集用制作ソースです。約50MBは最終ビルドの目標で、実ビルド容量は未測定です。

## 今回の改修

- 軒先に中空の瓦口、重なった瓦の段と焼き色差。開いた銅樋、巻き縁、金具、縦樋への継手
- ラーメンの器・半切り卵・海苔・肉・細い麺、焼き鳥の表面、器の釉薬を再調整。同じ共有画像を利用
- 8店舗の奥の品書きの鏡像と重なった裏面を修正
- 隣接巨木の描画を東西に分割。位置・UV・色・頂点共有を厳密に維持
- 無視されていた一部のroughness指定を修正。細い階段手摺・照明類のライトマップ割当係数を見直し
- 分割圧縮メッシュをGitの明示的なバイナリ属性にし、Windows式CRLF設定でのチェックアウトでも9個の圧縮資産が完全一致することを検査

## 規模と範囲

2,587,709三角形、1,059描画ソースバッチ。床・階段・透明壁の衝突バイナリ、49席、移動先と店員入口を維持。保護対象は隣接巨木の4→8分割以外の595バッチを厳密に維持し、分割後の603バッチを検査します。

[検証記録](Validation.md)と[独立レビュー](IndependentReview_2.9.0.md)。オフライン幾何検査は、指定領域と仮定した身体寸法に限ります。

## 後続の素材監査による訂正

v2.9付属のSurfaceRefinement文書で「実写Kawara」と記載した箇所は誤りでした。瓦のtile_clay画像一式は既存の手続き生成PBR素材です。実写スキャンは木材・樹皮・岩の4セットで、瓦の画像が実写であるという意味ではありません。今回保持した画像とプレビュー自体は変更していません。
