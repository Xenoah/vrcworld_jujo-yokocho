## 実書き出しの再検査

制作側の床サンプルだけに依存せず、保存されたJYWM描画・衝突データを別のパーサーで読み、三角形を身体領域へ切り出しました。BoxColliderは面だけでなく閉じた凸体として検査します。

- 190領域: 49席×着席胴体・退出・移動胴体、8店員入口、7階内経路、12移動先、12ボタン操作経路、4スポーン。失敗0
- 入口は検査で仮定した半径0.325m・頭上2.2m。一般経路は半径0.25m・頭上2.2m。着席は別の明記した胴体範囲
- 指定した経路全幅について、実際の上向き床・傾斜路の連続支持を確認
- R02/R03の下端で150mmの最初の踏段と傾斜路へ入る15接触だけを、名前・座標範囲・高さ160mm以下の個別条件で記録して許容。階段・手摺全体を検査から除外していません
- 新しい昇降機の木製取付板と金具を含め、操作経路の身体領域へ入る描画物なし
- 16カウンターBoxColliderだけが指定どおり短縮。その他61個と49席、移動先・向き・ラベル・名前は不変
- 木の支持枝に対する独立の符号付き立体角補助検査は3,540参照点で内部だけに埋まる点を検出せず。一般の全描画閉体に対する完全な体積包含検査ではありません

1280×800・64サンプルの公開用Blender画像2枚を独立に確認しました。店員入口では開口・紐で留めた巻き上げ暖簾・高い提灯が読み取れ、歩行画像では床の連続性・控えめな板差・継目・接地した丸椅子を確認。目に見える形状干渉や材質面の不具合は検出していません。両画像のGLBハッシュと保持した元PNGのハッシュも一致しました。

## 限界

いずれもオフライン検査です。Unity / Udon / Shaderコンパイル、実ライトベイク、Windowsビルド、VRChatのアバター・ジャンプ・しゃがみ・VRトラッキング・複数人試験は未実施。約50MBの実ビルド容量も未測定です。特定の身体寸法と指定領域の合格を、任意のアバターや自由な全室移動の保証として扱わないでください。
