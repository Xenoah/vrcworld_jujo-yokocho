# v2.12 独立照合・制作プレビューの記録

## 書き出し済みデータ

検証済みv2.11ソースアーカイブと、実際に再生成したv2.12のネイティブデータを別の読み取り専用手順で比較しました。

- 元の1,043バッチは全バイト一致
- 雪山の8バッチだけ承認済みRGBへ変更。位置・UV・alpha・三角形順は完全一致
- 舞台の4バッチだけ追加。39,892頂点・25,012三角形
- 元の舞台15バッチはすべて完全一致。古い樹冠保護資料では舞台の名前だけが記録されていたため、別のv2.10資料で元の15ペイロードも固定
- 全8分割ファイルの長さ・SHA-256・再結合・gzip展開結果を照合
- 衝突、49席、77個の明示BoxCollider、12階層移動先、指定動線は維持
- 追加造形に伴う高度変換の集計は+4バッチ・+39,892頂点。それ以外の高さ規則・変換カウンターは維持

## 舞台の実形状と材質

実際の書き出し済みfloat32三角形でも、4追加バッチの有限性・非縮退形状とUV・閉じたシェル・巻き順を確認しました。最も低い追加頂点は床上2.7574005m。頂部の上昇は5.9967mmで、固定した旧上限+6.1mm以内です。水平範囲は旧屋根のままです。

56個の露出した瓦口に対する168本の線、木栓16本、旧屋根面との余裕を再検査しました。隅棟に覆われた切断面や旧中実の棟は中空と扱っていません。

StageCypressの4枚のPBR参照だけを、既存のwood_planks_greyセットへ変更しました。他97材質、色、UV密度、粗さ倍率は維持。既存44画像ファイルも完全一致し、新しい画像はありません。同じカメラ・光・露出で、鏡状の床反射を抑え、木目と継手が見えることを比較しました。

## 実行範囲

元の全オフライン検査、雪の7項目、木材の6項目、屋根の単独検査を実行しました。追加した4舞台バッチも、最終的な頂点数・面数・位置と属性のハッシュへ固定しました。現行出力と合成した不正変更に対する5,078判定を実行。保護契約は未知の名前や大まかな接頭辞を許可せず、承認した変更だけを照合します。樹冠の経路・障害物・支持床・外周ガードも再検査しています。

画像の立ち位置は、明示した2視点について実床の中央+8方向の支持線と、半径0.25m・頭上2.2mの形状余裕を別に検査しました。北の視点は旧L4平面ではなく、増設した展望橋の実Colliderに支えられています。屋根全景用の高いカメラは歩行視点とは表記しません。

これらは仮定寸法のオフライン幾何検査です。UnityのCharacterController、任意のアバター、自由なルームスケール移動の検証ではありません。既知の旧GLBのゼロ法線2頂点は変わっておらず、Unity側の法線再計算は未実行です。

## 表示・実行上の限界

プレビューはBlender 4.3.2 Cyclesの実メッシュ描画です。法線・アルベドAOVによるOpen Image Denoiseを使い、元PNGをソースZIPに残します。生成画像による描き直しはありません。

雪の露岩は元の岩へ地形上つながりますが、全視点の投影で小片が出ない保証ではありません。元の粗い山頂の輪郭は残ります。共有した夕景の入力は、UnityとBlenderのピクセル一致を保証しません。

Unity/C#/Udon/HLSLの実コンパイル、ベイク、Windows Build & Test、VR両眼、FPS、最終圧縮容量は未確認です。約50MBは実ビルドの目標で、ソースZIPやgzip形状の容量ではありません。
