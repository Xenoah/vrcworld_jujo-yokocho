# 樹上横丁 / Tree-top Yokocho

Windows向けVRChatワールドの編集用Unity制作ソースです。ユーザー提供の設定資料と既存v2.0制作物を引き継ぎ、現実的な木造の質感と幻想的な眺望を作っています。

## v2.19.0 旗と立体看板、木の茶房サイン（未公開ソース候補）

8店それぞれに、厚みのある突き出し看板を追加しました。竜と熾火、麺鉢、旅人の鍋、魔女の帽子、木彫り風の月とカップ、星の瓶、竪琴、羽のある菓子箱です。3店には裾の形が違う布旗を添えています。茶房は木目のある厚い枠、明るい木の浮き彫り、木栓と実体のある吊り金具で仕上げました。

既存の店名・書体・照明色・内装はそのままです。新しいライト・材質定義・テクスチャ・シェーダーは増やさず、実形状の通路検査に看板も含めます。

[立体看板の範囲・実測費用・限界](Docs/RELEASE_NOTES_2.19.0.md)

## v2.18.0 茶房の和紙照明を木枠で仕上げる（未公開ソース候補）

月詠みの茶房の2つの照明を、暗い木の上下枠と控えめな縦格子で仕上げました。和紙風の発光面、既存2灯の位置・色・光量、照明全体の外形は維持しています。追加は144三角形・288頂点・1ソースバッチで、新しい材質・テクスチャ・ライトは増やしていません。

[今回の限定変更と検査範囲](Docs/RELEASE_NOTES_2.18.0.md)

## v2.17.0 RPGの店名・書体・店舗別の灯り（未公開ソース候補）

竜の熾火亭、風渡りの麺工房、旅人の燈火亭、宵闇の魔女、月詠みの茶房、星屑の蒸留所、吟遊詩人の隠れ家、妖精の菓子工房。各店の役割に合わせた全文の店名と紋章、ライセンス付きの日本語書体を看板へ焼き込みました。文字を横伸ばしせず、実際の看板の縦横比に合わせています。

炭火の金色、麺工房のミント白、スナックの淡い紫、茶房の月白と翡翠、バーの青緑、音楽店の藍色、菓子店のアイボリーと淡い薔薇色へ。既存の店内照明15灯だけを調整し、店舗外359灯はそのままです。灯数は増やさず、点滅や色のアニメーションも追加していません。Unity側の色・有効強度・発光材質を変更しており、Blenderの色調補正だけではありません。

## v2.16から引き継ぐ、個性の異なる8店舗

屋根・店構え・カウンター・椅子・看板・作業場を店舗ごとに作り直しました。炭火、ラーメン、おでん、茶房、菓子店に加え、スナック、カクテルバー、音楽バーを設けています。夜の店は8店舗中3店舗（37.5%）です。

49個の座席IDは維持し、内装に合わせて座席位置・退出先・店内のBoxColliderを更新しました。外周の床・階段・落下防止壁、衝突メッシュ、店舗外815バッチ、元の鉢と下部構造40部品は厳密に保護しています。旧シーンの見た目だけを差し替えず、必ず同じ版のソースからシーン全体を再生成してください。

現行の全体は2,708,881頂点・2,304,649三角形。v2.14比で491,389頂点・344,958三角形少なくなりました。一方、ソースの描画バッチは1,058から1,145へ87増えています。これらはソース実測であり、実測描画コール数・FPS・Unity配信容量ではありません。

布・和紙・釉薬の異なる不透明シェーダー、控えめな青緑の空、方向が揃いすぎない海面の細波を維持。未使用頂点・遠い海の平面分割・完全に隠れた内部面を削減し、雪山の稜線・積雪・法線も改善しています。近くで見える木工や樹冠は一律に簡略化していません。

[8店舗の構成と検査範囲](Docs/ShopPersonalityDesign.md)・[8店舗の設計変更](Docs/RELEASE_NOTES_2.16.0.md)・[材質と限界](Docs/FantasyShaderIntegration.md)・[平面削減](Docs/PlanarOptimization.md)・[雪山](Docs/MountainQuality.md)

- 巨木の横丁、8店舗・49席、4デッキ、環状路、暖簾と提灯
- 真下に森林と同規模の巨木。北は街道・円形城郭都市・雪山、南は海と島
- 外周、内周、階段側面の見えない非トリガー落下防止Collider
- 実壁に通路が切られていた2か所を修正し、障害物を差し引く通路検査を追加
- Unity2022.3.22f1 / Built-in / VRChat Worlds SDKを想定

約50MBは最終Windowsワールドの目標です。ソースZIP容量ではありません。実ビルド容量は未測定です。

Unity / Udon / Shaderのコンパイル、ベイク、VRChat Build & Test、VR実機試験は未実行です。

近い樹冠を葉の形状へ置き換え、城門・城壁・海岸の細部を追加。雲の切れ間から森林・街道・城郭都市・海を望めます。遠景とVR表示の仕上げは継続して確認が必要です。

地上設備から幹へ続く水道・ガス・電線、横丁の56本の電灯と配線、通信設備・点滅障害灯を追加。

横丁の実際の床を100m持ち上げ、標高134〜152mへ移設。地上は0mのまま、212mの樹冠まで1,416段の連続階段と配線を再構成。実メッシュの身体余裕・床支持を再検査。

実形状で93.816〜123.604mの雲海を配置（最大揺れ込み124m未満）。地上・52m・102mの3段階ポンプ設備、155mの貯水台と6基の多段ポンプを接続。設備は景観演出であり、実際の揚水性能を認証したものではありません。

中央の環状路内側へ、四方に開いた能舞台風の演技床と屋根を追加。周囲の床と連続し、身体余裕・頭上・視線を検査。
